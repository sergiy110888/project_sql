### Описание проекта    
Составленные запросы для анализа базы данных вакансий на рынке труда.
:arrow_up:[к оглавлению](_)


### Какой кейс решаем?    
Провести анализ состояния рынка труда на основе результатов проведенного исследования. 
Использование запросов SQL по средствам языка Python

**Что практикуем**     
Учимся составлять запросы под разнообразные условия выборки данных, при этом учимся находить взаимосвязь между полученными результатами
